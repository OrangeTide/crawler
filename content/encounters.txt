# weighted list of monster ids. Table 0 is left empty, so safe areas (the
# town and interiors, which resolve to area 0) spawn nothing.
#
#   area NAME N   assign an area to table N
#   table N       begin filling table N
#   mon ID W      add monster ID with weight W to the current table
#
